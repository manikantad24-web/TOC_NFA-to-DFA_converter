# Contributing

Contributions and improvements are welcome.

## Before submitting a change

1. Keep the project dependency-free unless a dependency is clearly necessary.
2. Preserve the existing NFA → DFA algorithm behavior.
3. Test normal NFAs and NFAs containing ε-transitions.
4. Test both accepted and rejected strings.
5. Test DFA minimization after conversion.
6. Check the browser console for errors.
7. Keep generated files and local environment files out of commits.

## Pull requests

Please describe:

- What changed
- Why the change was needed
- How it was tested
- Any UI or algorithm behavior that changed
